Upgrade the product presentation so it stands out in a hackathon demo.

- dark charcoal / graphite base

## Design principle

Use:

Premium futuristic minimalism
+ selective glass-prism depth
+ restrained AI motion
+ subtle 3D/illustrative accents

Do NOT use:
- full-page glassmorphism
- heavy neomorphism
- random bright gradients everywhere
- generic “SaaS dashboard” boxes
- cartoon illustrations
- noisy decorative effects
- visual clutter

The product should feel:
- premium
- modern
- AI-native
- precise
- memorable in a demo

## Visual system goals

Refine the UI using:

### 1. Stronger surfaces
- cleaner card hierarchy
- fewer flat generic bordered boxes
- better spacing and padding
- stronger typography hierarchy
- more deliberate use of depth and layering

### 2. Selective glass-prism accents
Use sparingly on:
- Ask AI panel
- summary cards
- processing states
- evidence/citation highlights
- premium empty states

The majority of the UI should still remain clean and readable.

### 3. Futuristic AI accents
Use subtle:
- cyan + restrained violet/indigo interplay
- soft glow only around key AI areas
- layered gradients
- intelligent hover states
- premium focus states
- polished loading/progress states

### 4. Selective 3D illustration / motif usage
Use only if tasteful and on-theme.

Potential motifs:
- abstract signal orb
- waveform / audio intelligence motif
- mesh / prism / neural surface
- subtle holographic object
- AI processing visual motif

Good places:
- dashboard/library empty states
- Ask AI empty state
- summary / intelligence sections
- no-meeting-selected or no-recording states

Do NOT let 3D art dominate the app.
It should support the product, not turn it into a landing page.
